## 四、图形体系规范（新增/修改图标必须遵守）

1. **画布**：24×24 viewBox，`fill="none"` + `fill-opacity="0"`（pre-commit #17 强制）。
2. **线宽**：主轮廓 1.6，次级细节 1.2，细线 1.0-1.1。
3. **颜色 sentinel**（仅限 ffffff master）：
   - `#FFFFFF` → 主题主色（渐变亮端）；`#AAAAAA` → 主色加深 30%（渐变暗端）
   - `#000000` → 语义强调色（每图标固定，见 `DIAG_ACCENT`/`SEMANTIC_ACCENT`）
   - `#777777` → 软灰 #64748B（固定）
4. **强调色纪律**：每图标语义强调色元素 ≤ 2 处，避免彩色噪音。
5. **互斥性**：同组及跨组图标在 28px 下不得形似（本次修复的典型冲突：盾牌 ×2、圆柱 ×2、双节点连线 ×2、折线路径 ×2、地球 ×2）。
6. **辅形**：`masters-45/nd-diag-*-a.svg` 仅画 accent 补充细节（哨兵 `#666666` → `DIAG_ACCENT` 深浅两色），不得重复主形内容。
7. **改动流程**：改 `ffffff/` 或 `masters-45/` 后必须运行 `python3 scripts/generate-colored-icons.py`（pre-commit #19 强制）。
8. **动画**：新增图标需在 `DiagnosticMeta.cpp` 指定语义匹配的 `DiagAnimType`。
9. **借鉴来源**：Lucide / Tabler / Material Symbols 的通用隐喻（如 `wifi`+`info`、`router`、`shield-check`、`gauge`、`folder-up`、`terminal`），不使用任何厂商商标图形（如 PostgreSQL 大象、MySQL 海豚）。

## 四·bis 第二轮修订（用户反馈，2026-08-14 下午）

一轮设计经用户反馈后对 16 项重做（判定已并入 §二 表格），其余维持一轮设计：

1. **采用 Lucide 官方路径（用户要求"严格参看网上"，逐字核对）**：WiFi Information（wifi 官方三弧逐字 + info 徽章）、DNS Integrity（shield-check 逐字 v1.31）、Internet Connectivity & Speed（gauge 逐字 v1.31，无自加点缀）、DNS Resolution（replace 官方发布版 v0.263–v0.416 逐字，经典版并注释版本来源）、MQTT（share-2 逐字，原版连线无自加箭头）。
2. **数据库四联**（PostgreSQL/MySQL/Redis/MongoDB）：统一 PostgreSQL 式圆柱外壳 + 文字标签（Postgres/MySQL/Redis/MongoDB），内部差异化细节（三层内椭圆 / 中心强调点 / 双侧点 / 内叶形弧），品牌强调色（蓝/琥珀/红/绿）。
3. **Telnet/SSH/FTP**：统一终端提示符 + 协议文字，提示符字形区分（`>` / `#` / `$`）；下划线光标**由 QML 驱动闪烁**（DiagBlock.qml `terminalCursor`，SVG 不画下划线——QtSvg 不支持 SMIL 动画）。
4. Wired → ethernet-port 网口插座；Network Adapters → 一排网口交换机；Cellular → radio-tower 信号塔；IP Configuration → "IP" + 192.168.1.1 地址文本。
5. 动画：FTP Path→**Type**（终端提示符，与 Telnet/SSH 同族）。
6. **已知限制（审计记录在案）**：
   - **fill-opacity 继承缺陷（已修复）**：根元素 `fill-opacity="0"` 按规范继承，此前 Chrome 等渲染器下全部填充元素（文字标签/圆点）隐形；现已给所有含 `fill` 的元素显式注入 `fill-opacity="1"`（ffffff + masters-45 共 50 文件，烘焙透传），Chrome/QtSvg 双修。HTML 预览需将 #000000/#AAAAAA/#777777 哨兵替换为可见色（见 `icon-comparison` 页生成器 bake_preview）。
   - `masters-45/*-a.svg` 辅形已烘焙入 qrc，但运行时无消费方（预留层）。
   - 24px 画布内文字标签在 28px 瓦片下不可读，作"标签隐喻"使用；详情页/报告以文本名称为准。
